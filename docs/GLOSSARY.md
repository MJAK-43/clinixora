# Glossaire métier (brouillon)

| Terme | Définition |
|-------|------------|
| Patient | Personne prise en charge ; dossier dans le système |
| Acte / prestation | Consultation, examen, imagerie, hospitalisation, etc. |
| Rôle | Ensemble de permissions (remplace progressivement les niveaux `lvl` legacy) |
| Action agent | Opération invocable par l’IA (`action_key`), soumise à policy + toggle admin |
| Toggle admin | Interrupteur global pour autoriser ou non l’agent à exécuter une action |

À compléter au fil du projet.
